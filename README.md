# IPV6
# IPv6 Theory

IPv6 stands for **Internet Protocol Version 6**. It is the newer version of the Internet Protocol and was developed mainly to solve the shortage of IPv4 addresses.

## Main Features

- IPv6 uses **128-bit addresses**.
- An IPv6 address has **8 groups**.
- Each group contains **16 bits**.
- IPv6 uses **hexadecimal** numbers (0–9 and A–F).
- It provides a very large number of IP addresses.
- IPv6 supports automatic address configuration.
- IPv6 provides better support for modern network communication.

## IPv6 Example

`2001:0db8:85a3:0000:0000:8a2e:0370:7334`

This IPv6 address has:

**8 groups × 16 bits = 128 bits**

## IPv6 vs IPv4

| Feature | IPv4 | IPv6 |
|---|---|---|
| Address Size | 32 bits | 128 bits |
| Format | Decimal | Hexadecimal |
| Groups | 4 | 8 |
| Separator | `.` | `:` |
| Example | `192.168.1.10` | `2001:db8::1` |

## Viva Definition

IPv6 is a **128-bit Internet Protocol** used to identify devices and communicate over a network.
